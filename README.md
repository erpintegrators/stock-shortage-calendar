# Stock Shortage Calendar for Odoo 20

Solvync Inc.

Review warehouse shortages, explain stock movements, compare saved baselines, assign follow-ups and simulate receipt timing. Warehouse scans and My actions, Overdue and Unassigned queues support daily review.

Download the matching release from the [product page](https://erpintegrators.com/odoo-stock-shortage-calendar/). The module supports Community and Enterprise with Inventory on hosting that permits Python addons.

Release 20.0.1 uses internal manifest version 20.0.1.0 for installer compatibility. Read the module README before installation. Previous private test builds require an administrator-managed update because their version numbers were higher.

The [user training guide](docs/stock-shortage-calendar-training.pdf) includes screenshots and a worked practice example.
